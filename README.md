# Whisper Corpus Studio — Releases

Repositório público de **distribuição** do Whisper Corpus Studio.

Aqui ficam apenas os **instaladores** (`Setup.exe`) e suas assinaturas (`.sig`)
publicados como *Releases*. O **código-fonte é privado**.

O aplicativo verifica automaticamente a última versão publicada aqui e, antes de
instalar, confere a **assinatura Ed25519** do instalador.
